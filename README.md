# Jump King Clone (RL-ready)

A faithful clone of the base game *Jump King* (Nexile, 2019) — no DLC — built for
reinforcement-learning research: deterministic headless simulation, programmatic
control, rich state observations and a Gymnasium environment.

Work in progress. See `docs/PLAN.md` for the plan and `docs/RESEARCH.md` for the
researched mechanics.
